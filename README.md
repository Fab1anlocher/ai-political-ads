# AI Political Ad-Generator

> Bachelor Thesis – Berner Fachhochschule

Web-App zur Generierung personalisierter politischer Werbebilder für Schweizer Volksabstimmungen.

## Live-Demo

https://ai-political-ads.vercel.app/

## Kurzüberblick

- **Stack:** Next.js, TypeScript, Tailwind CSS
- **Funktion:** Erfassung von Profil-/Umfragedaten und KI-basierte Bildgenerierung
- **KI-Anbindung:** OpenAI bzw. Google Gemini
